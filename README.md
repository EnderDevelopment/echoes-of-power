# Echoes of Power

Echoes of Power is a Minecraft plugin designed to enhance gameplay with powerful features, lore, and exploration elements. It integrates seamlessly with performance mods and offers compatibility checks to ensure smooth operation. The plugin includes a variety of commands and functionalities to enrich the Minecraft experience.

## Install

1. Download the plugin JAR file from the releases section.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your server to enable the plugin.

## Use

1. Start your Minecraft server with the plugin installed.
2. Use the `/ciao` command to greet yourself.
